# results/

This directory receives the CSV outputs written by the scripts in
`scripts/`:

| File | Written by | Contents |
|---|---|---|
| `calibration_long_<station_id>.csv` | `scripts/run_calibration.py` | Full 18-row (N, L) sweep for one station (Eq. 5) |
| `calibration_optimal.csv` | `scripts/run_calibration.py` | One row per station: (N\*, L\*, r\*, n_obs) 
| `sensitivity_regional_vs_local.csv` | `scripts/run_sensitivity_analysis.py` | (N\*, L\*, r\*) obtained with HadEWP regional precipitation vs. local rain-gauge data, for each station |

These files are not stored in version control (see `.gitignore`): they are
regenerated by running the corresponding script, and are derived entirely
from the data in `data/` and the parameters in `config/`.
